# react-native-readium-lcp

[![NPM version](https://img.shields.io/npm/v/react-native-readium-lcp.svg?color=success&label=npm%20package&logo=npm)](https://www.npmjs.com/package/react-native-readium-lcp)
![This project is released under the MIT license](https://img.shields.io/badge/license-MIT-blue.svg)

[Readium LCP](https://www.edrlab.org/readium-lcp/) DRM for
[`react-native-readium`](https://www.npmjs.com/package/react-native-readium), on iOS and Android.

**[Documentation](https://5-stones.github.io/react-native-readium/lcp)** ·
[Installation](https://5-stones.github.io/react-native-readium/lcp/installation) ·
[API reference](https://5-stones.github.io/react-native-readium/lcp/api)

```sh
yarn add react-native-readium-lcp
```

Requires liblcp, EDRLab's private library, which this package can't ship.
[Contact EDRLab](https://www.edrlab.org/contact/) for it; the documentation covers setting it up.
