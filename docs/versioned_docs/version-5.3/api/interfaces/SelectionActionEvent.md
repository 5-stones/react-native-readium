# SelectionActionEvent

Reported by `onSelectionAction` when the user picks one of the `selectionActions`.

## Properties

### locator

```ts
locator: Locator;
```

Where the selection is, e.g. to create a highlight there.

***

### selectedText

```ts
selectedText: string;
```

***

### actionId

```ts
actionId: string;
```

The `id` of the action picked.
