# react-native-readium

[![NPM version](https://img.shields.io/npm/v/react-native-readium.svg?color=success&label=npm%20package&logo=npm)](https://www.npmjs.com/package/react-native-readium)
![This project is released under the MIT license](https://img.shields.io/badge/license-MIT-blue.svg)

An ebook reader for React Native, built on the [Readium](https://readium.org/) toolkits: EPUB and
PDF on iOS, Android and web.

**[Documentation](https://5-stones.github.io/react-native-readium/)** ·
[Installation](https://5-stones.github.io/react-native-readium/docs/getting-started/installation) ·
[API reference](https://5-stones.github.io/react-native-readium/docs/api)

```sh
yarn add react-native-readium react-native-nitro-modules
```

For DRM-protected books, see
[`react-native-readium-lcp`](https://www.npmjs.com/package/react-native-readium-lcp).
